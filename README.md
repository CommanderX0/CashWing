# CashWing 💸

**CashWing** is an Android demo wallet application developed as a university project. It demonstrates digital wallet concepts, user accounts, and simulated money transfers using Firebase.

> **Disclaimer:** CashWing is an educational and demonstration project only. It does not handle real money or provide real financial services.

## ✨ Features

- **User Registration & Login:** Create accounts and log in using a phone-number-based identity and PIN.
- **Digital Wallet:** View your demo wallet balance.
- **Simulated Transfers:** Send demo balance to other registered users.
- **User Search:** Find recipients using their phone numbers.
- **Transaction History:** Review previous demo transactions.
- **Firebase Integration:** Store and synchronize account and wallet data using Firebase Authentication and Cloud Firestore.
- **Demo Environment:** All balances and transfers are virtual.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Internet connection
- A compatible Android device or emulator

### Installation

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize.
4. Make sure the Firebase configuration file (`google-services.json`) is available inside the `app` directory.
5. Run the application on an Android device or emulator.

## 🔥 Firebase Integration

CashWing uses Firebase Authentication and Cloud Firestore to manage demo accounts and synchronize wallet information.

The distributed project is configured to connect to its associated Firebase project. Users running the application will connect to the same backend environment.

**Note:** This is a shared demonstration environment, not an isolated database for each installation.
